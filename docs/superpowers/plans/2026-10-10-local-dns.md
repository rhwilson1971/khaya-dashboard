# Local DNS Implementation Plan

**Goal:** Use Pi-hole at 10.0.10.53 for the boma.home.arpa domain.

**Architecture:** Share a bounded standard-library DNS resolver between ICMP
monitoring and heartbeat requests. Keep fixed network configuration in a
small config module and expose it as read-only settings. Allow the local
domain in LAN-mode HTTP Host validation and retain same-origin checks.

**Tech stack:** Python 3.10+, SQLite, standard-library unittest, vanilla JS.
