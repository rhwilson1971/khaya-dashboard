Understand health

Online means a successful ping or authenticated heartbeat. Offline means repeated missed checks or an expired heartbeat. Unknown means there is no usable check yet, monitoring is disabled, or the collector encountered an error.

Keep it running

The collector works while the Python service runs, even with the browser closed. This dashboard measures network reachability, not CPU, memory, or application health.

Launch with python3 -m network.server. LAN access and heartbeat setup are described in the project README.
